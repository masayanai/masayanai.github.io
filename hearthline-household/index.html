Hearthline household

Hearthline household is a private application used by a single family for household scheduling and for keeping track of school assignments. It is not offered to the public and has no users outside that family. It connects to Google as two apps: "Hearthline household" (calendar) and "Hearthline household intake" (assignment mail).

Privacy policy

What it accesses. With the family's consent, and only with these two Google scopes:

  • Calendar. It reads and writes events on the family's own Google Calendar, using the scope https://www.googleapis.com/auth/calendar.events.
  • Assignment mail. It reads, without changing, sending or deleting anything, the messages in one dedicated family mailbox that receives school assignment notifications, using the read-only scope https://www.googleapis.com/auth/gmail.readonly.

It requests no other Google data.

How it is used. Calendar data is used only for the family's household scheduling. Assignment mail is used only to list the family's school assignments and to notice when expected assignment mail has stopped arriving. Each message is processed in memory and the full message is not stored. The app keeps only the assignment details the family needs and, for each message, a few bookkeeping details: its Gmail message and thread identifiers, the time it arrived, its labels, its format and its number of attachments. Neither calendar data nor assignment mail is given to any third party, sold, or used for advertising, and neither is used to train any AI model.

Where data stays. Data the app stores stays on the family's self-hosted server.

Limited Use. Hearthline household's use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access. Access can be revoked at any time from the Google Account's third-party access settings.

Contact. The owner of the household Google accounts that operate the app.
