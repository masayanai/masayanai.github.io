Hearthline household

Hearthline household is a private application used by a single family for household scheduling. It is not offered to the public and has no users outside that family.

Privacy policy

What it accesses. With the family's consent, the app reads and writes events on the family's own Google Calendar, using only the Google Calendar scope https://www.googleapis.com/auth/calendar.events. It requests no other Google data.

How it is used. Calendar data is used only for the family's household scheduling. It is not given to any third party, not sold, and not used for advertising.

Where data stays. Data the app stores stays on the family's self-hosted server.

Limited Use. Hearthline household's use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access. Access can be revoked at any time from the Google Account's third-party access settings.

Contact. The owner of the household Google account that operates the app.
